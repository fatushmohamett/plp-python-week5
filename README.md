# PLP Python Week 5 - Password Generator & Your Own Module

This assignment practices using Python modules, functions, default parameters, and creating my own module.

## Files

* `password_generator.py` - Generates random passwords using the `random` and `string` modules.
* `helpers.py` - Contains the `tables_needed()` and `welcome()` functions.
* `main.py` - Imports the `helpers` module and uses its functions.

The hardest part was understanding how to create my own module and import it into `main.py`. It was challenging at first, but I learned how `helpers.py` can provide functions that `main.py` can use.
